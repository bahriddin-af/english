# English — ish papkasi

Ingliz tili speaking mashg'ulotlarim shu yerda. Har kuni shu papkani ochaman.

## Papka tuzilishi

| Papka / fayl | Nima uchun |
|---|---|
| `00-KONTEKST.md` | **Eng muhim fayl.** Yangi AI sessiyasida shuni beraman — u holatimni to'liq tushunadi |
| `01-kunlik-jurnal/` | Har kunlik yozuv. `KUN-01.md`, `KUN-02.md`... Shablon: `_SHABLON.md` |
| `02-xatolar/` | Xatolar daftari — takrorlanadigan xatolarim |
| `03-sozlar/` | Monolog paytida topolmagan so'zlarim, gap ichida |
| `04-yozuvlar/` | Diktofon yozuvlari (audio). `kun-01.m4a`, `kun-30.m4a`... |
| `05-hujjatlar/` | Reja va yo'l xaritasi linklari, PDF'lar, kitoblar |
| `PROGRESS.md` | Oylik o'lchov — o'sishni faqat shu yerda ko'raman |

## Kunlik tartib

1. **06:30** — `01-kunlik-jurnal/` dan bugungi kun faylini oching
2. Shadowing 15 daq → monolog 20 daq (diktofonga yozing → `04-yozuvlar/`)
3. Topolmagan so'zlarni `03-sozlar/2026-XX.md` ga yozing
4. **20:00** — sherik bilan English hour
5. Sessiyadan keyin xatolarni `02-xatolar/` ga qo'shing
6. Kun faylida `[x]` belgilang

## Muhim eslatmalar

- **Diktofon yozuvini o'chirmang.** 1-kun yozuvi 30-kuni kerak bo'ladi.
- **Har oyning 1-kuni** `Tell me about yourself` savoliga 2 daqiqa javob
  bering va yozib oling. Bu sizning o'lchov nuqtangiz.
- O'sishni his qilib bo'lmaydi — faqat eski yozuv bilan taqqoslab ko'rish mumkin.
